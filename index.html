About Sorting Algorithms

Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order.

Time Complexity: O(n²)

Best Case: O(n)

Space Complexity: O(1)

Bubble Sort is simple and easy to understand, making it suitable for beginners learning sorting algorithms.

Insertion Sort

Insertion Sort builds a sorted array one element at a time by placing elements in their correct positions.

Time Complexity: O(n²)

Best Case: O(n)

Space Complexity: O(1)

It performs efficiently for small datasets and nearly sorted arrays.

Selection Sort

Selection Sort repeatedly selects the minimum element and places it at the correct position.

Time Complexity: O(n²)

Best Case: O(n²)

Space Complexity: O(1)

Selection Sort minimizes the number of swaps but is inefficient for large datasets.
